5. Viewport and Responsive Media

Responsive Image

The image automatically adjusts to its container. Its original aspect ratio is preserved.

Responsive Video

The video maintains a 16:9 aspect ratio and fits the available screen width.

Viewport and Media Query Information

  • Viewport: The meta viewport tag sets the page width to the device width.
  • Grid: Auto-fit and minmax create responsive grid columns.
  • Media Queries: The layout changes at 768px and 480px.
  • Images: Width 100% and height auto preserve image proportions.
  • Video: Width 100% and aspect-ratio 16/9 provide responsive sizing.
