1. Non-Semantic Elements

Non-semantic elements do not describe the meaning of their content. The most common examples are <div> and <span>.

DIV Example

This heading is inside a div

The div groups related content together. It has no specific semantic meaning by itself.

HTML is easy to learn when practiced regularly. The span styles only a small part of the text.

2. Semantic Elements

Semantic elements clearly describe the purpose of their content to browsers, developers, and assistive technologies.

Examples of Semantic Elements

  • <header> — introductory content
  • <nav> — navigation links
  • <main> — primary page content
  • <section> — a thematic section
  • <article> — independent content
  • <aside> — related supplementary content
  • <footer> — closing information

Why Use Semantic HTML?

Semantic HTML improves document structure and supports accessibility. It also helps search engines understand the roles of different page sections.

Remember to focus on meaningful HTML structure rather than using elements only for their appearance.

4. HTML5 Semantic Tags Demonstration

This page demonstrates all the requested tags: article, aside, figcaption, figure, footer, header, hgroup, mark, nav, section, and time.

Tag Summary

  • article: Self-contained article content.
  • aside: Supplementary information.
  • figcaption: Caption for a figure.
  • figure: Self-contained media or illustration.
  • footer: Closing or author information.
  • header: Introductory content.
  • hgroup: Groups a heading with related secondary heading content.
  • mark: Highlights relevant text.
  • nav: Navigation links.
  • section: Thematically grouped content.
  • time: Machine-readable date or time.
